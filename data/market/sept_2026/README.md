# Official German market data snapshot — September 2026

## Files

- `market_panel_15min.csv`: DE-LU day-ahead prices and German national public-power series aligned with the supplied 15-minute reBAP export.
- `fcr_capacity_clearing_4h.csv`: German FCR capacity settlement prices by delivery date and product from the official result overview.
- `mfrr_capacity_clearing_4h.csv`: German mFRR capacity price statistics by delivery date and product from the official result overview.
- `raw/`: original supplied reBAP/XLSX exports and the raw Energy-Charts API responses used to create the normalized files.
- `manifest.json`: period, row counts, source names, and known gaps.

## Provenance

- Day-ahead price and public power: Energy-Charts API, licensed as indicated by the API response (Bundesnetzagentur/SMARD, CC BY 4.0).
- reBAP: supplied Netztransparenz export, 15-minute German uniform imbalance price.
- FCR and mFRR: supplied regelleistung.net September 2026 result-overview exports.
- Retrieval date for API data is recorded in `manifest.json`; original exports are preserved under `raw/`.

## Caveats

September has 2,880 quarter-hour intervals. The supplied reBAP file contains `N.A.` for all 96 intervals on 30 September; these are left blank and must not be imputed as observed market prices. This snapshot does not contain a German aFRR capacity-market clearing result file or June–August 2026 reBAP/reserve data. The available September prices therefore cannot be used to claim that the manuscript's June–August backtest has been re-run on actual market prices.

The national load and generation series are not VPP telemetry. Auction clearing prices also do not imply that a hypothetical VPP would have cleared: product eligibility, prequalification, bid size/step, symmetry, availability, activation energy, and non-delivery settlement must be represented before computing participant revenue. This data bundle is inputs only; no optimization results or profit claims are generated by this script.

## Reproduction

Run `python data/scripts/extract_september_2026_market_data.py` from the workspace root. The script uses only the Python standard library and writes normalized outputs under `data/processed/market_data_2026-09/`.
